# ⚙️ گردش‌کارهای اتوماسیون (Automation Workflow)

**مجموعه‌ای از گردش‌کارهای کاربردی اتوماسیون با استفاده از n8n**

[🇬🇧 English](README.md) | [🇮🇷 فارسی](README.fa.md)

این مخزن شامل مجموعه‌ای از Workflowهای اتوماسیون است که با هدف ساده‌سازی فعالیت‌های روزمره، افزایش بهره‌وری و توسعه راهکارهای هوشمند مبتنی بر هوش مصنوعی با استفاده از ابزار **n8n** طراحی و توسعه داده می‌شوند.

## 🚀 گردش‌کارهای موجود

### ۱. ساخت خودکار رزومه (AI Resume Builder)

یک گردش‌کار خودکار برای ساده‌سازی و تسریع فرآیند ساخت رزومه با کمک هوش مصنوعی.

**قابلیت‌های اصلی:**
- تولید خودکار محتوای رزومه
- استفاده از هوش مصنوعی برای تولید و سازمان‌دهی اطلاعات
- کاهش فعالیت‌های دستی و افزایش بهره‌وری
- ارائه Workflow در قالب فایل JSON قابل وارد کردن به n8n

**فایل Workflow:** `Resume-Builder/resume-builder.json`

## 🛠️ فناوری‌ها و ابزارها

- **n8n:** پلتفرم اتوماسیون و مدیریت گردش‌کارها
- **AI / LLMs:** تولید و پردازش هوشمند محتوا
- **JSON:** ساختار ذخیره‌سازی و انتقال Workflowها
- **APIs & Integrations:** ارتباط با سرویس‌ها و ابزارهای خارجی

## ⚡ راه‌اندازی و استفاده

۱. ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/YOUR_USERNAME/Automation-Workflow.git
```

۲. وارد محیط n8n شوید.

۳. از بخش Workflows گزینه Import from File را انتخاب کنید.

۴. فایل JSON مربوط به Workflow موردنظر را وارد کنید.

۵. تنظیمات و دسترسی‌های موردنیاز را پیکربندی کنید.

۶. Workflow را اجرا کنید.

## 🔐 امنیت

- کلیدهای API، رمزهای عبور و اطلاعات محرمانه را در مخزن قرار ندهید.
- اطلاعات دسترسی را به‌صورت امن در n8n ذخیره کنید.
- پیش از اجرای Workflowها، تنظیمات آن‌ها را بررسی کنید.
